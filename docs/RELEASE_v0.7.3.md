# PixelReceipt 0.7.3

Android 0.7.3／code 17，沿用 `com.momonong.pixelreceipt.mobile`、`PixelReceipt` 名稱與永久簽章。本版的 Git 發布、正式後端／APK 下載與手機安裝，各依實際交付證據核對。

送出一次後，App 前景自動更新待處理收件，返回 App 立即查詢。單一非阻塞控制器每輪最多 8 筆，選取項優先、其餘輪替；一般進度約 5 秒、等待資格／額度約 30 秒。離開前景停止手機輪詢，中央辨識持續。

只有已按送出並持久保存完整原請求與續傳資格的批次，才可在暫時斷線或單次請求逾時後以 10／30／60 秒退避續傳。所有照片、說明、key、body 與 hash 沿用。已取得中央收件編號或結果未知時只查詢原工作，不另建模型工作、不換提供者、不自動入帳。舊版未記錄續傳資格的 frozen 資料保留手動續傳。

登入失效、明確拒絕與本機儲存失敗不自動重送。按全域停止會保存所有未確認續傳的停止意圖，切換頁面不會停錯收件，重建後仍保持；停止設定無法保存時明確顯示警告。已由中央接收的工作不會因停止手機同步而取消。

等候畫面顯示免費資格、額度與設定等阻擋原因。實際自動追蹤時顯示「進度自動更新中」，以返回收件匣為主操作，保留立即更新作備用；需人工處理與舊版 frozen 不冒充自動運作。一般手機與窄螢幕大字體沿用現有原生版型。

本版不續期免費資格、不新增供應商／付費備援／推播或常駐手機服務；目前因資格到期而等待的正式收件，仍需資格恢復才會由中央接續。資料庫 schema、帳務算法、原帳本、照片與認證皆不變。後端只新增精確的 code 17／0.7.3 APK 配對，保留其他下載安全檢查。

設計與驗收：[安全續傳與自動進度計畫](plans/2026-11-14-auto-progress-plan.md)。本機工程、簽章成品、Git、正式部署、手機實測與人工接受分別留證；合成測試不代表目前真實收據已完成辨識。

本機工程驗證：568 項 Android 測試、lintDebug、assembleDebug 及 487 項後端測試皆通過；包含既有帳務、更新、原生畫面與版本下載安全案例。
