# 收據操作介面預覽

這是供討論與操作確認的介面範例，使用虛構資料，不連接正式 App、後端或真實帳本，不上傳圖片，也不會改動手機資料。原生 Android／後端已依本預覽整合刪除及作廢；正式行為與交付狀態見 [手機使用說明](../../MOBILE_APP.md) 及 [0.5.1 發行說明](../../RELEASE_v0.5.1.md)。本目錄仍是獨立虛構資料示範，不包含 APK。

## 開啟

直接用瀏覽器開啟 [index.html](index.html)，或將這份檔案交給既有靜態 HTTP 服務。`index.html` 已包含所有樣式、腳本與所需圖示，開啟時不需要 Codex、網路、套件安裝或建置。

建議使用支援原生 `dialog` 與 CSS `light-dark()` 的現代瀏覽器。配色跟隨瀏覽器的明暗模式，版面適用 320px 以上寬度。

獨立頁面只在記憶體中模擬狀態，重新整理即還原範例。嵌入支援的對話環境時，fragment 可保存該預覽的互動狀態；兩者都不會寫入正式帳本。

## 三條測試路徑

每條路徑開始前重新整理獨立頁面。

1. **檢查與入帳**：收件匣會顯示日用小舖「未入帳」、巷口早餐與手作茶飲「已完成」。打開日用小舖，核對 NT$100＋NT$160，按「確認入帳」。帳本支出應從 NT$140 變為 NT$400；回收件匣仍能看到三張已完成收據。
2. **刪除未入帳收據**：從日用小舖右側「更多操作」選「刪除收據」。先按「取消」或 Escape，收據與金額應保持不變。再次操作並確認，日用小舖才會消失，兩張已完成收據仍在，帳本支出維持 NT$140。
3. **作廢已入帳帳目**：在收件匣或帳本對巷口早餐選「作廢帳目」。原因預設「未註明」，可另行選擇；取消不改資料。確認後留在原分頁，支出應由 NT$140 變為 NT$45。收件匣保留「已作廢」收據；帳本勾選「查看已作廢」可看到歷史，該筆不計入有效支出。

## 刪除與作廢的差別

| 操作 | 適用狀態 | 收據紀錄 | 帳本支出 |
| --- | --- | --- | --- |
| 刪除收據 | 未入帳 | 從本預覽移除，介面沒有復原操作 | 不受影響 |
| 作廢帳目 | 已入帳／已完成 | 保留作廢狀態與原因 | 排除該筆金額 |

初始範例為日用小舖 NT$260（NT$100＋NT$160）、巷口早餐 NT$95（NT$60＋NT$35）、手作茶飲 NT$45。支出只加總有效帳目，因此初始為 NT$140。金額以整數最小貨幣單位計算。

正式 App 採邏輯刪除，保留原圖、紀錄與備份，介面沒有復原按鈕；已入帳只能作廢，保留歷史且不計有效支出。未知刪除／作廢保留原 ID、revision、原因與同一請求供查核。預覽互動不能代替正式部署、手機更新或人工驗收。

## 維護與重建

`receipt-actions.fragment.html` 是介面與互動的唯一原稿。`index.html` 是為了支援離線雙擊開啟而納入版本控制的產出檔，請勿直接修改。

修改 fragment、`lucide-subset.js` 或授權檔後，在 repository 根目錄執行：

```bash
python3 docs/previews/receipt-actions/build_preview.py
python3 docs/previews/receipt-actions/build_preview.py --check
```

建置只使用 Python 標準函式庫，讀取本目錄來源並更新同目錄 `index.html`；不需網路或專屬環境。`--check` 只核對產出是否一致，不會寫檔。

`lucide-subset.js` 收錄 Lucide 1.8.0 的七個官方圖示節點與極小的本機替換函式，僅供此預覽。原始專案為 [Lucide](https://github.com/lucide-icons/lucide)，ISC／Feather MIT 授權全文保留於 `LUCIDE-LICENSE.txt`，亦內嵌在獨立頁面。
