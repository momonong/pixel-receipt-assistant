# pixelreceipt 0.7.1

Android versionName 0.7.1／versionCode 15。應用程式顯示名稱改為 `pixelreceipt`，移除「收件匣」後綴；首頁、設定及本機帳本標題共用相同名稱資源。收件匣仍是收據管理功能。

沿用 `com.momonong.pixelreceipt.mobile` 與永久簽章，可在 App「設定 → 檢查更新」下載，再交由 Android 覆蓋安裝。不需 USB、不解除安裝、不清除資料。後端 APK 白名單加入 15／0.7.1；資料庫維持 schema 5，財務計算與辨識來源不變。

0.7.0 的生活分類、三餐、商家、縣市分析及舊帳目「分析標籤」補填流程保留。未知分類、縣市和餐別顯示待補，不憑空填入；補標籤不改原入帳金額、用途或照片。使用步驟見 [手機使用說明](MOBILE_APP.md) 與 [生活支出分析](LIVING_SPENDING_ANALYSIS.md)。

改名候選已通過 505 項 Android 測試、lintDebug、assembleDebug；82 項分類、餐別、商家、縣市及標籤補填後端測試通過。版本白名單及正式 APK 介面另以發布檢查驗證。簽章、實際公開下載、正式服務及手機安裝的狀態以本次交付紀錄為準，不以工程通過代替人工驗收。

此版未改 APK 快取清理策略：App 內下載成功後以同一檔名替換舊包，可能保留最新一份快取；不按版本累積多份。先前由瀏覽器下載的 APK 不由 App 管理。
